## Conclusions and limits

The claim that compaction never succeeded in the last five days is contradicted by the October 9 commit. The available logs cannot distinguish a reasoning-budget exhaustion from a provider abort or Pi's own signal abort for the reported failures. Orientation completions are not saved as ordinary assistant messages, and the existing generic exception discards `stopReason` and whether `event.signal` was aborted. No retained evidence proves `stopReason: length`, a provider timeout, or an orientation call on `gpt-5.6-sol`.

Source proves a liveness defect independently: `checkpoint-handoff.ts` caps completion at 4096 tokens and rejects length/error/aborted responses with one generic error; `native-compaction.ts` catches that error and returns `cancel: true`. A provider-local failure therefore cancels Pi compaction even when Pi's own signal is live. Add outcome diagnostics and bounded retry/fail-open behavior rather than claiming an unobserved provider cause. SDK inspection further rejects the assumed high-thinking inheritance: registry `complete` uses API-specific options, not simple `reasoning` options; the handoff does not inherit the agent thinking level. Codex Responses defaults toward mapped off/none and does not serialize `maxTokens` into its request at all (`node_modules/@earendil-works/pi-ai/dist/api/openai-codex-responses.js`, payload builder). Thus a 4096-token cap consuming high Codex reasoning is not supported as the cause. New result diagnostics retain normalized stop reason, caller abort state, output/reasoning usage, model and latency without logging transcript or raw provider errors.

Source also proves the coverage/retirement mismatch: coverage counts all active exact keys, retirement records every fully hidden block, while native summary admission follows retention tiers and token budget. The current renderer actually admits tier-selected active blocks, including blocks crossing the cut; the audit's description of a fully-hidden-only renderer does not exactly match this checkout. Gate and retirement must instead derive from the final admitted summaries, preserving the host's cut.
